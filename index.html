ローマ字タイピング練習

日本語入力(IME)がオンになっています。半角/全角キーで直接入力に切り替えてください。

読み込んだファイルはブラウザの中だけで扱います。サーバへは送りません。

打鍵は物理キー位置で判定します。配列が合っていないと ; : などが正しく入りません。

ファイル形式

Google 日本語入力のローマ字テーブルと同じ形式に、省略可能なタグ列を足したものです。 

入力	出力	次の入力	第1カテゴリ	第2カテゴリ	第3カテゴリ
sa	さ
tt	っ	t
nk	ん	k
;	っ			soku			direct
kz	かん		sei,row.ka		ext.hatsu,dan.an
@alwaysEnabled	std,legacy
  • 入力 が重複した場合は、後に定義した行で上書きされます。
  • 出力 と 次の入力 がどちらも空の行はコメントとして無視されます。 コメント行にはタブを入れないでください。
  • 4〜6 列目のタグは省略できます。このページでは全タグが有効なので、タグ付きのテーブルもそのまま読めます。
  • 文字コードは UTF-8 / UTF-16 / Shift_JIS を自動判定します。
※ #{ … #} で囲んだ数行は、ランダム出題中でも並び替えずに続けて出題されます。

ローマ字ガイドは既定でオフです。最短の打鍵列に BackSpace が必要な テーブルではローマ字だけでは表せず、有効打鍵としての BackSpace と 打ち直しの BackSpace も区別できないためです。

BackSpace = 1 文字を取り消し / Esc = やり直し / Enter = 結果画面からもう一度
