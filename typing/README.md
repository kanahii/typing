# ローマ字タイピング練習

HTML + プレーンな JavaScript のみ（ビルド不要・外部ライブラリなし）。
`index.html` をブラウザで開けば動きます（`file://` で可）。

## ローマ字テーブル

「設定」からタブ区切りテキストを読み込むと、入力パターンを差し替えられます。
Google 日本語入力のローマ字テーブルと同じ形式です。

```
入力	出力	次の入力
```

```
sa	さ
si	し
tt	っ	t
nk	ん	k
```

- `入力` が重複した場合、後に定義した行で上書きされます。
- `出力` と `次の入力` がどちらも空の行はコメントとして無視されます。
- 文字コードは UTF-8 / UTF-16 / Shift_JIS を自動判定します。

`次の入力` は、変換後に入力欄へ残す文字列です。`tt → っ (次: t)` なら
`tta` が「った」に、`nk → ん (次: k)` なら `nka` が「んか」になります。

**「次の入力」に残った文字も入力の一部**です。`出力` を一度も経由しない
かなも入力できます。例えば次のテーブルでは `ka` が未定義でも、`k` だけで
「か」が入力できます（`k` を打つと入力欄に「か」が残るため）。

```
k		か
かi	き
かu	く
```

## 画面

```
今日はいい天気ですね          ← お題 (表示文)
きょうはいいてんきですね      ← よみ (見本。減らず、次に打つかなに印)
──────────────────
入力
きょうはいい|                 ← 入力欄。空から増えていく
kyouhaiitenkidesune          ← ローマ字ガイド (打ち終わった分は淡色)
```

入力欄には次の 3 つが並びます。

| 表示 | 意味 |
| --- | --- |
| 一致している入力 | よみと合っている先頭部分 |
| ずれた入力（赤地） | よみと合わなくなった部分。消すまで残る |
| 未確定のローマ字（点線） | 変換待ち。`きょ` を打つ途中の `ky` など |

### ミスタイプ

**打ち間違えてもローマ字変換は止まりません。** 打鍵はテーブルどおりに
変換され続け、その結果が入力欄に出ます。「その打ち方をすると代わりに何が
入力されるのか」がそのまま見えます。

| 打ちたいもの | 実際の打鍵 | 入力欄 |
| --- | --- | --- |
| `きょ` | `kya` | `き` + **`ゃ`**（赤） |
| `で` | `da` | **`だ`**（赤） |
| `さ` | `ta` | **`た`**（赤） |

よみとずれた時点でミスに加算され、枠が赤くなります。ずれたまま打ち続けても
変換は続き（そのつどミス加算）、BackSpace で消すまで先へは進めません。

テーブルのどの規則にもならない打鍵（`kd` の `k` など）は、変換されずに
その文字のまま入ります。これも IME と同じ挙動です。

### 判定について

打鍵はまず IME と同じ要領でテーブルにかけ、変換結果を積んでいきます
（目標とは無関係に、常にテーブルどおり）。そのうえで、積まれた入力を
お題のよみと突き合わせて正誤を決めます。

- 入力がよみの先頭一致のままで、かつ残りを打ち切る打鍵が存在する … 正解
- よみからずれた／未確定のバッファがどう転んでもよみにならない … ミス

「残りを打ち切れるか」は、テーブルを実際にシミュレートして探索します。
`し` = `si` / `shi` / `ci` のような複数表記も、`k` → 「か」のような
「次の入力」経由の入力も、まとめてこの探索で扱われます。どの打ち方でも
正解になります。

画面のローマ字ガイドは**最短の打鍵数**になる表記を表示します。同じ打鍵数の
表記が複数ある場合は、テーブルで**先に定義した行**が使われます。実際に
打った綴りではなく、いまの位置に至る最短の綴りで表示されます
（`shi` と打っても `si` と表示されます）。

既定テーブルは単独の `n` を「ん」にしていません（Google 日本語入力と同じく
`nn` / `n'` / `n` + 子音）。単独の `n` を許したい場合は
`romaji-default.js` 内の該当行のコメントを外すか、読み込むテーブルに
`n<TAB>ん` を追加してください。

## お題

既定は 24 問。「設定」から `表示文 <TAB> よみ` のタブ区切りテキストを
読み込むと差し替えられます（`よみ` を省くと表示文をそのまま使います）。
現在のローマ字テーブルで打ち切れないお題は自動で除外されます。判定は
テーブルの実シミュレーションなので、「次の入力」経由でしか入力できない
かなも打鍵可能として扱われます。

英数字などは、テーブルに規則が無ければそのまま入力されるので打てます
（`CPU 100%` など）。ただし規則がある文字は変換されるため、既定テーブル
では小文字の `abc` は「あbc」になり、そのままでは打てません。

## 操作

- 任意のキー … 開始
- BackSpace … かな 1 文字を取り消し
- Esc … やり直し
- Enter … 結果画面からもう一度

### BackSpace の挙動

お題の中なら何文字でも戻れます。上から順に判定します。

1. 未確定のローマ字が残っているとき … それを捨てる
   （`った` に `tt` まで打った状態 → `っ` を残して `t` を捨てる）
2. 無いとき … 入力を 1 文字戻す
   （`きゃ` を打った状態 → `き` まで戻る）

2 はローマ字ではなく**変換後の 1 文字（かな単位）**です。

`きゃ` のつもりで `ki` と打ってしまった場合、BackSpace で `き` を消して
`kya` と打ち直せます。

戻った位置のローマ字表示は、そのかなに到達できる**最短の打鍵**に書き直されます
（例: `kya` から 1 回戻ると `ki` 表示になり、残りは `lya…`）。
BackSpace は打鍵数・ミス数には数えません。

IME はオフ（直接入力）にしてください。オンのまま打つと画面上部に警告が出ます。
