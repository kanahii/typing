# ローマ字タイピング練習

HTML + プレーンな JavaScript のみ（ビルド不要・外部ライブラリなし）。
`index.html` をブラウザで開けば動きます（`file://` で可）。

## ローマ字テーブル

「設定」からタブ区切りテキストを読み込むと、入力パターンを差し替えられます。
Google 日本語入力のローマ字テーブルと同じ形式です。

```
入力	出力	次の入力
```

```
sa	さ
si	し
tt	っ	t
nk	ん	k
```

- `入力` が重複した場合、後に定義した行で上書きされます。
- `出力` と `次の入力` がどちらも空の行はコメントとして無視されます。
  判定は空かどうかだけなので、`#` で始めてもタブと出力があれば規則として
  読まれます。コメント行にはタブを入れないでください。
- 文字コードは UTF-8 / UTF-16 / Shift_JIS を自動判定します。

`次の入力` は、変換後に入力欄へ残す文字列です。`tt → っ (次: t)` なら
`tta` が「った」に、`nk → ん (次: k)` なら `nka` が「んか」になります。

**「次の入力」に残った文字も入力の一部**です。`出力` を一度も経由しない
かなも入力できます。例えば次のテーブルでは `ka` が未定義でも、`k` だけで
「か」が入力できます（`k` を打つと入力欄に「か」が残るため）。

```
k		か
かi	き
かu	く
```

## 画面

```
今日はいい天気ですね          ← お題 (表示文)
きょうはいいてんきですね      ← よみ (見本。減らず、次に打つかなに印。
                                 まとめて確定する分はまとめて印)
──────────────────
入力
きょうはいい|                 ← 入力欄。空から増えていく
[ キーボード図 ]              ← 次に押すキー / 押されたキーを表示
```

次に何を打つかはキーボード図が示します。ローマ字ガイド (打鍵列を淡色で
消費していく表示) もありますが、既定ではオフです → [ローマ字ガイド](#ローマ字ガイド)

よみの印は、**1 回の確定でまとまって入力されるぶん**に付きます。`きゃ` は
`kya` の 1 回で確定するので `きゃ` にまとめて印が付きます。何文字ぶんに
なるかはローマ字テーブル次第です。

ただし `次の入力` で続けて入力される分は含みません。`tt → っ (次: t)` なら
`った` ではなく `っ` だけに印が付きます (`た` は次の打鍵で確定するため)。

入力欄には次の 3 つが並びます。

| 表示 | 意味 |
| --- | --- |
| 一致している入力 | よみと合っている先頭部分 |
| ずれた入力（赤地） | よみと合わなくなった部分。消すまで残る |
| 未確定のローマ字（点線） | 変換待ち。`きょ` を打つ途中の `ky` など |

### キーボード

読み込むテーブルによっては、ローマ字表記とかけ離れたマッピングになります。
その場合ローマ字ガイドは読みづらいので、キー位置でも示せるようにしています。

キーに出るのは**刻印ではなく、いまそのキーを押したら入力される文字**です。
ローマ字テーブルと現在の入力状態から毎回計算します。

```
バッファが空   … A に「あ」、I に「い」、K に「k」
k を打った後   … A に「か」、I に「き」、K に「っk」、Y に「ky」
ky を打った後  … A に「きゃ」、O に「きょ」
```

打ちかけが消えるキー（`k` の後の `s` など）は暗く落とします。
`k → 次の入力 か` のようなテーブルなら、K キーには最初から「か」が出ます。

| 表示 | 意味 |
| --- | --- |
| 黄色の枠 | 次に押すキー。Shift が要る文字なら Shift も光ります |
| 水色 | いま押したキー（正解） |
| 橙色 | いま押したキー（より少ない打鍵で打てる打ち方がある） |
| 赤 | いま押したキー（ミス） |
| F と J の下線 | ホームポジションの目印 |

### 打鍵数が増える打ち方

同じかなでも打鍵数が変わる打ち方があります。速く打っていると気づかないので、
**打鍵数が増える打ち方をしたキーだけ橙色**にしています（通常より少し長く
点灯します）。打鍵数が変わらない打ち方は普段どおりの水色です。

| 打ち方 | 判定 |
| --- | --- |
| `しゃ` を `sya` / `sha` | どちらも 3 打鍵 → 水色 |
| `じゃ` を `zya` | `ja` で済むので `z` の時点で橙色 |
| `じゃ` を `jya` | `y` の時点で橙色 |
| `った` を `ltu` + `ta` | `l` の時点で橙色（2 打鍵ぶん増えるため） |
| `にちは` を `chiha` | `tiha` で済むので `c` の時点で橙色 |

減らせる打鍵数の合計は、結果画面に「短縮余地」として出ます。

これは**お題を打ち切った時点の入力**で数えます。打鍵ごとの積み上げではなく、
「そのお題を打ち終えるのに使った打鍵数」と「理論値」の差です。そのため、
橙色に気づいて BackSpace で最短の打ち方に直せば加算されません。
何度打ち直しても、最後に残った打ち方だけが数に入ります。

| 打ち方（`じゃんけん`、理論値 7 打鍵） | 橙の点灯 | 短縮余地 |
| --- | --- | --- |
| `jankenn` | 0 | 0 |
| `zyannkenn` | 2 | 2 |
| `zya` → BackSpace → `jankenn` | 1 | 0 |
| 遠回りと打ち直しを 3 回繰り返して最後は最短 | 3 | 0 |
| 最短に直してから、また遠回りで打ち切る | 3 | 2 |

入力がお題からずれている間は、次に押すキーとして **BackSpace** が光ります。

「設定」→「表示」で、キーボードの配列（JIS / US）の切り替えと、
キーボード・ローマ字ガイドそれぞれの表示 / 非表示ができます。

### ローマ字ガイド

打鍵列を並べて、打ち終わった分を淡色にしていく表示です。**既定ではオフ**で、
「設定」→「表示」から出せます。

出るのは**実際に押すキー**です。未確定バッファの中身ではないので、
`ky → 次の入力 きy` のようなテーブルでも `ky` と出ます（`きy` は出ません）。

オフにしている理由は次の 2 つです。

- 最短の打鍵列に **BackSpace が必要になるテーブルがある**。ローマ字の並び
  だけでは表せません（`ky → 次の入力 きy` のようなテーブルでは、`き` を
  単独で入力するのに BackSpace が要ります）
- 有効打鍵としての BackSpace と、ミスの修正・打ち直しの BackSpace を
  区別する必要が出てしまう

なお現在の最短打鍵の計算は **BackSpace を使わない前提**です。そのため、
BackSpace が要るお題は「打てない」と判定されて除外されます。

### ミスタイプ

**打ち間違えてもローマ字変換は止まりません。** 打鍵はテーブルどおりに
変換され続け、その結果が入力欄に出ます。「その打ち方をすると代わりに何が
入力されるのか」がそのまま見えます。

| 打ちたいもの | 実際の打鍵 | 入力欄 |
| --- | --- | --- |
| `きょ` | `kya` | `き` + **`ゃ`**（赤） |
| `で` | `da` | **`だ`**（赤） |
| `さ` | `ta` | **`た`**（赤） |

よみとずれた時点でミスに加算され、枠が赤くなります。ずれたまま打ち続けても
変換は続き（そのつどミス加算）、BackSpace で消すまで先へは進めません。

テーブルのどの規則にもならない打鍵（`kd` の `k` など）は、変換されずに
その文字のまま入ります。これも IME と同じ挙動です。

### 判定について

打鍵はまず IME と同じ要領でテーブルにかけ、変換結果を積んでいきます
（目標とは無関係に、常にテーブルどおり）。そのうえで、積まれた入力を
お題のよみと突き合わせて正誤を決めます。

- 入力がよみの先頭一致のままで、かつ残りを打ち切る打鍵が存在する … 正解
- よみからずれた／未確定のバッファがどう転んでもよみにならない … ミス

「残りを打ち切れるか」は、テーブルを実際にシミュレートして探索します。
`し` = `si` / `shi` / `ci` のような複数表記も、`k` → 「か」のような
「次の入力」経由の入力も、まとめてこの探索で扱われます。どの打ち方でも
正解になります。

キーボードが示す「次に押すキー」は、**最短の打鍵数**になる打ち方です。同じ
打鍵数の打ち方が複数ある場合は、テーブルで**先に定義した行**が使われます
（`しゃ` は `sya` と `sha` のどちらでも 3 打鍵ですが、`sya` が案内されます）。

既定テーブルは単独の `n` を「ん」にしていません（Google 日本語入力と同じく
`nn` / `n'` / `n` + 子音）。単独の `n` を許したい場合は、`romaji-default.js`
または読み込むテーブルに `n<TAB>ん` の行を追加してください。

## お題

既定は 24 問。「設定」から `表示文 <TAB> よみ` のタブ区切りテキストを
読み込むと差し替えられます（`よみ` を省くと表示文をそのまま使います）。
現在のローマ字テーブルで打ち切れないお題は自動で除外されます。判定は
テーブルの実シミュレーションなので、「次の入力」経由でしか入力できない
かなも打鍵可能として扱われます。

英数字などは、テーブルに規則が無ければそのまま入力されるので打てます
（`CPU 100%` など）。ただし規則がある文字は変換されるため、既定テーブル
では小文字の `abc` は「あbc」になり、そのままでは打てません。

## 操作

- 任意のキー … 開始
- BackSpace … かな 1 文字を取り消し
- Esc … やり直し
- Enter … 結果画面からもう一度

### BackSpace の挙動

IME と同じく、**画面に出ている入力の末尾 1 文字**を消します。お題の中なら
何文字でも戻れます。

1. 未確定のローマ字が残っているとき … その末尾 1 文字
   （`sha → しゃ` の定義で `sh` まで打った状態 → `s` が未確定で残る）
   （`った` に `tt` まで打った状態 → `っ` を残して `t` を消す）
2. 無いとき … 確定した入力の末尾 1 文字
   （`きゃ` を打った状態 → `き` まで戻る）

2 はローマ字ではなく**変換後の 1 文字（かな単位）**です。

消した結果、未確定文字がテーブルのどの規則の接頭辞でもなくなっても、
**未確定のまま残します**。次の打鍵で規則に合えば変換され、合わなければ
確定文字になります（変換できない打鍵と同じ扱い）。

```
ky      <TAB>        <TAB> きy
きya    <TAB> きゃ
```

このテーブルで `ky` まで打つと未確定文字は `きy`。BackSpace で `き` が残り、
続けて `ya` と打てば `きゃ` になります。

`きゃ` のつもりで `ki` と打ってしまった場合、BackSpace で `き` を消して
`kya` と打ち直せます。

戻った位置のローマ字表示は、そのかなに到達できる**最短の打鍵**に書き直されます
（例: `kya` から 1 回戻ると `ki` 表示になり、残りは `lya…`）。
BackSpace は打鍵数・ミス数には数えません。

IME はオフ（直接入力）にしてください。オンのまま打つと画面上部に警告が出ます。
