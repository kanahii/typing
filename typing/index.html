ファイル形式

Google 日本語入力のローマ字テーブルと同じ形式です。 1 行が 入力 / 出力 / 次の入力 の 3 列で、区切りはタブ。 

sa	さ
si	し
tt	っ	t
nk	ん	k
  • 入力 が重複した場合は、後に定義した行で上書きされます。
  • 出力 と 次の入力 がどちらも空の行はコメントとして無視されます。
  • 文字コードは UTF-8 / UTF-16 / Shift_JIS を自動判定します。
